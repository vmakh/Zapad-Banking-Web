# Заміна Inter: типографічна пропозиція

2026-10-15. [Живе порівняння](/font-pairings.html): три однакові інтерактивні екрани, Personal / Business, головна / платежі / операції. Посилання під прикладом відкриває повний екран. Попапи використовують ті самі спільні компоненти та успадковують шрифт.

## Рекомендація

**Unbounded + Onest.** Unbounded 500 залишається для заголовків, Onest — для основного тексту, навігації, полів, кнопок і сум. На мою оцінку, нейтральний рисунок Onest найкраще врівноважує характер Unbounded і підтримує спокійний банківський інтерфейс.

| Пара | Враження та компроміс | Офіційне джерело |
| --- | --- | --- |
| Unbounded + Onest | Нейтральна, відкрита, придатна для щоденних дій. Рекомендована пара. | [Google Fonts metadata](https://github.com/google/fonts/blob/main/ofl/onest/METADATA.pb) |
| Unbounded + Manrope | М’яка геометрія, дружній характер; ширші літери потребують уваги до довгих підписів. | [Google Fonts metadata](https://github.com/google/fonts/blob/main/ofl/manrope/METADATA.pb) |
| Unbounded + IBM Plex Sans | Точний, технічний характер, доречний у таблицях і Business. | [IBM Plex](https://github.com/IBM/plex), [Google Fonts metadata](https://github.com/google/fonts/blob/main/ofl/ibmplexsans/METADATA.pb) |

Опис характеру шрифтів — дизайнерська оцінка. Усі три сімейства мають кирилицю та SIL OFL 1.1. Ліцензії збережено біля незмінених файлів у `src/assets/font-proposals/`; вони дозволяють використання й вбудовування шрифтів, включно з комерційними проєктами, з дотриманням умов OFL.

## Ролі в обох профілях

- Unbounded 500: заголовок сторінки 24 px (22 px на найвужчих екранах), заголовок попапа 20 px.
- UI-шрифт 400: основний текст 17 px; допоміжний 15 px; примітки 13 px.
- UI-шрифт 500: навігація й підписи.
- UI-шрифт 600: секції 20 px та фінансові суми; суми з табличними цифрами.
- UI-шрифт 650: кнопки 17 px. Усі три локальні variable-файли підтримують цю вагу.

Розміри й колірна система залишаються чинними; великий баланс адаптується до ширини панелі. Для порівняння змінюється тільки `--bank-body` в ізольованому preview. Параметр `bodyfont` приймає лише onest / manrope / plex; невідоме значення лишає основний Onest. `locale=uk` діє лише в пам’яті preview. До вибору Onest застосунок використовував стек Inter / system без локального файла Inter; зараз основним шрифтом є локальний Onest.

## Походження файлів і перевірка

Незмінені variable TTF та OFL завантажені 2026-10-15 з офіційного [google/fonts](https://github.com/google/fonts): `ofl/onest/Onest[wght].ttf`, `ofl/manrope/Manrope[wght].ttf`, `ofl/ibmplexsans/IBMPlexSans[wdth,wght].ttf`. Локальні імена спрощено без зміни внутрішніх назв шрифтів. Onest застосовано в основному застосунку; альтернативи завантажуються лише сторінками порівняння / preview. Запитів до Google Fonts під час перегляду немає.

Перевірено таблицю cmap усіх трьох файлів: Ґґ Єє Іі Її, ₴, €, 0–9 присутні. SHA-256 та результати: [glyphs.json](qa/font-pairings/glyphs.json). Сторінка перевіряє завантаження всіх чотирьох ваг через Font Loading API та показує статус. Браузерна перевірка охоплює Personal, Business, український текст, заголовки Unbounded, UI-шрифти та попап переказу.

## Застосовано 2026-10-15

За вибором користувача Onest став основним UI-шрифтом Personal та Business. Unbounded збережено для заголовків. Onest і ліцензію перенесено до `src/assets/Onest-Variable.ttf` та `src/assets/Onest-OFL.txt`; єдине оголошення @font-face міститься в `src/styles/fonts.css`. Початковий опис незміненого основного стеку вище стосується етапу порівняння. Баланс тепер масштабується за шириною панелі й довжиною повного локалізованого значення, без розриву суми або коду валюти.
