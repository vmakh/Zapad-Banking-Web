# UI component registry

Згенеровано командою npm run generate:ui-registry з поточного коду. Не редагувати вручну: зміни перезаписуються генератором.

[Дизайн-система і практичні контракти](DESIGN_SYSTEM.md) · [Візуальні правила](../DESIGN.md)

React/Vite, Tailwind 4. Alias @/ maps to src/. Use shared cn() from @/app/components/ui/utils. Theme: src/styles/theme.css, src/styles/design-system.css and the final overrides in src/styles/index.css.

## Прямі імпорти модулів (73)

Ця таблиця сканує value-import у файлах src/. Вона відрізняє імпорти з екранів і банківських компонентів від внутрішніх залежностей бібліотеки ui/. Імпорт не доводить, що компонент відображається на поточному маршруті. «—» означає відсутність прямих імпортів; це не рекомендація видаляти модуль. Локальні компоненти сторінок, hooks і зовнішні бібліотеки не входять до каталогу експортованих компонентів.
